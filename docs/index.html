Built to stay out of your way

A minimal interface over a serious engine.

Local & private

Embeddings run on-device with EmbeddingGemma via ONNX Runtime. Nothing is uploaded.

Hardware accelerated

Uses CUDA, DirectML or CoreML when present and falls back to CPU. Indexing runs on background threads so the app stays responsive.

Quotes, passages, documents

Choose result granularity. Matches show their surrounding context, page number or timestamp, plus a circular match meter.

See it in the PDF

Every PDF hit comes with a thumbnail of the page, the match highlighted. Click to open the PDF already scrolled to that spot.

Folders, bookmarks & tags

Organize media in real subfolders, bookmark favorites, add your own tags, and filter by any combination.

Portable libraries

A library is a folder plus one JSON index. It opens on Windows, macOS and Linux, and exports to a single .fuzz file you can import anywhere.

Lightweight

A native Tauri app: no Electron, no accounts, no runtime to install.

Build from source

Needs Rust, Node 18+, and on Windows the WebView2 runtime.

git clone https://github.com/ESAK9781/fuzz.git
cd fuzz
npm install
npm run dev      # run in development
npm run build    # produce a native installer

For true semantic search, click Install model in the app: it downloads the EmbeddingGemma ONNX model (about 330 MB, once) and runs it on-device. Until then fuzz uses a keyword-matching mode.
